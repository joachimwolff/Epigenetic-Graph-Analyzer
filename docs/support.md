# Support and citation

## Help and bug reports

Questions, bug reports and feature requests: the
[issue tracker](https://github.com/joachimwolff/Epigenetic-Graph-Analyzer/issues) of the repository. Please include
the command line, the log (`--verbose`) and the version (`egaCreateGraph --version`).

## Archive

Version 1.0.0 of EGA, the results and the processed data of the manuscript are archived on Zenodo:
[10.5281/zenodo.23725671](https://doi.org/10.5281/zenodo.23725671). The archive holds

| Record | Content |
|---|---|
| `01_software.tar.gz` | source code of version 1.0.0, `REPRODUCE.md`, environment |
| `02_results.tar.gz` | results of all analyses of the manuscript |
| `03_processed_inputs.tar.gz` | inputs of EGA processed from public data: CHiCAGO calls, capture designs, DESeq2 tables, mouse fold enrichment |
| `04_multiway_intermediates.tar.gz` | multi-way matrices and Pore-C / HiPore-C clusters |

`REPRODUCE.md` maps every figure and table of the manuscript to its script.
